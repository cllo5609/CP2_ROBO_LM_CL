# CP2_ROBO_LM_CL
To run this simulation, navigate to the root directory for this project and run the command "python CP2_startercode.py" or "python3 CP2_startercode.py" depending on system setup. 
To view the solution video for the bonus problem, download the "final_path.mp4" file from the root directory of this project and run it in your local media player.
